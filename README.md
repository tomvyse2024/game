# NEON RUSH — Arcade Racing

A mobile-friendly browser racing mini game built with plain HTML, CSS and JavaScript.

## Run locally
1. Open `index.html` in Chrome, Safari, Firefox or Edge.
2. Press **Start Engine**.
3. Use **← / →** or **A / D** on a keyboard. On mobile, use the on-screen left/right controls.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `neon-rush`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your game URL will look like:
   `https://YOUR-USERNAME.github.io/neon-rush/`

No build tools, frameworks, external images, or paid hosting are required.
